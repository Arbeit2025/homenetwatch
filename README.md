# homenetwatch（おうちネットワーク見える化）

自宅LANにつながっている機器をざっくり把握するための、単一ファイル Flask の小さなWebツールです。

## これは何をするもの？

- 実行しているPCが所属するサブネット（例: `192.168.1.0/24`）を自動で推定して表示します
- 「スキャン開始」ボタンを押すと、そのサブネット内のホストへ到達確認（ping ＋ 主要ポートのTCP接続確認）を行い、見つかった機器を IPアドレス・ホスト名・開いているポートの一覧表で表示します
- 確認するポートは 22 / 80 / 443 / 445 / 3389 です
- データベースは使いません。結果は保存されず、外部に送信されることもありません

## ⚠️ ローカル実行専用です

このツールは **自分の自宅PC上で動かして使う** ことを前提にしています。
Render のようなクラウドサーバーに置いても、そのサーバーからは自宅のLANは見えません（見えるのはサーバー側のネットワークになってしまいます）。公開サーバーへのデプロイは想定していません。

## 安全上の設計

- スキャン範囲は「実行マシン自身の所属サブネット（/24）」だけに固定されています。画面にもAPIにも、範囲を指定する入力はありません。**他人のネットワークや外部のアドレスを走査することはできません**
- 自分の管理していないネットワークに対しては使わないでください。自宅LANの把握だけを目的としたツールです
- アプリは `127.0.0.1`（このPCからだけアクセス可能）で待ち受けます

## 起動方法

```bash
pip install -r requirements.txt
python app.py
```

起動したらブラウザで http://127.0.0.1:5000 を開いてください。

## テスト

```bash
python -m unittest discover -s tests
```

テストはネットワークへの実アクセスを行わず、到達確認・ポート確認はモックで置き換えています。

## 構成

- `app.py` … 本体（単一ファイル）
- `tests/test_app.py` … unittest
- `requirements.txt` … Flask のみ
